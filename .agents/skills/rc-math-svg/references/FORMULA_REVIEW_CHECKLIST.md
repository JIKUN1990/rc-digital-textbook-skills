# Formula and resource review checklist

- [ ] Original editable formula or source image is recorded and retained when supplied.
- [ ] Edition, page/figure identifier, and usage permission are recorded; unknown items say “待核验”.
- [ ] Symbols, signs, dimensions, units, and displayed axis units are consistent.
- [ ] Every parameter has a source-backed default and bounds, or the missing range is marked pending.
- [ ] Piecewise boundaries, continuity, and behavior outside the valid domain are explicitly defined.
- [ ] Formula display is separate from the registered calculation function.
- [ ] The SVG is sampled from the mathematical model, not traced from screenshot pixels.
- [ ] Numerical tests cover representative values, endpoints, branch transitions, and rejected inputs.
- [ ] Browser checks cover default, changed parameter, boundary, reset, and export behaviors.
- [ ] Review report distinguishes local checks from standards review and cloud-platform acceptance.
