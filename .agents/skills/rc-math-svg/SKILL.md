# rc-math-svg

将教材中的数学关系实现为可审查、可复用的二维交互曲线资源。共享 TypeScript/D3/SVG 引擎与教材独立模块分开管理；每个资源使用单独 JSON 配置。公式文本只负责显示，实际计算由显式注册的安全模型函数完成。禁止用 `eval` 或 `new Function` 执行公式文本。

## 标准工作流程

1. **读取原始教材图和公式。** 优先使用可编辑的教材公式来源；若只有截图，先读取截图并逐项转写。记录教材、版本、页码或图号及使用许可。截图中的模糊字符、上下标或曲线细节标记“待核实”。
2. **识别变量、单位和参数范围。** 建立符号表，区分自变量、因变量、派生量、单位、默认值、上下界与步长，并判断哪些量适合交互控制。
3. **核对公式及适用条件。** 与用户指定版本的教材、规范或可追溯来源核对公式、边界、强度等级和适用范围。来源缺失或参数范围不明时标“待核验”，不得自行补写规范数值或外推结论。
4. **选择计算模型及 SVG 模板。** 从 `FormulaModelRegistry` 选择或新增带唯一 ID、参数约束、边界行为及测试用例的模型。使用 MathCurve 模板绘制函数采样曲线；区分教材图示、解释动画和工程计算。
5. **生成配置文件。** 为每个资源在 `modules/<resourceId>/config.json` 写入标题、章节、公式 LaTeX、模型 ID、参数、单位、轴范围、曲线、参考线、关键点、物理说明、适用条件及来源/规范元数据。
6. **生成交互网页。** 使用 ParameterSlider、FormulaDisplay、CurveInspector、MathCurve 与 CurveExport；保证参数更新、公式显示和曲线计算使用同一模型状态。变量需有单位和可访问标签。
7. **执行数值与边界测试。** 验证代表值、端点、分段连续性、参数限制、范围外行为、配置轴单位及重置/参数更新逻辑。不得声称未运行的测试已通过。
8. **执行浏览器视觉检查。** 检查默认、参数变化、边界和窄屏布局；确认无 JavaScript 错误、公式溢出、控件遮挡或曲线越界。可用浏览器自动化时保存检查截图。
9. **输出独立模块和简短审查报告。** 记录文件、模型 ID、来源状态、执行过的测试及结果、视觉检查状态和仍待核验事项。没有真实平台上传时不得声称平台兼容性已验证。

## 配置及实现约定

- JSON 公式字符串由 KaTeX 以非信任模式渲染；永远不作为代码执行。
- 新资源优先仅增加配置并复用已注册模型；只有计算关系不同或新增边界语义时才增加必要的模型函数与测试。
- 每个曲线分段用函数采样，不按教材截图像素描线。
- 超过适用边界时返回 `null` 或明确无效结果，显示提示并停止绘制/外推有效响应。
- 规范号、范围和来源不完整时保持“待核验”；示例数值必须标出工况与教学用途。
- 配置模板见 `assets/config.template.json`；公式核验表见 `references/FORMULA_REVIEW_CHECKLIST.md`。
