# RC Digital Textbook Skills

A collection of four Codex skills for interactive reinforced-concrete teaching resources.

## Included skills

- `rc-material-interactive` — synchronized material curves and Three.js specimen interactions.
- `rc-math-svg` — reusable SVG interactions for equations, curves, and parameter relationships.
- `rc-section-3d-derivation` — synchronized 3D sections, SVG force diagrams, calculations, and derivation steps.
- `rc-section-calculator-studio` — reinforced-concrete section design and reinforcement detailing calculators.

## Use in a project

Copy the desired skill folder(s) from `.agents/skills/` into the target project's `.agents/skills/` directory. Keep each skill's `SKILL.md` together with its referenced support files.

Some workflows refer to project-specific shared components; read each skill's prerequisites before applying it in another project.
